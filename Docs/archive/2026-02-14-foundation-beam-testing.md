## テスト4: FEM解析の正確性テスト

### 4.1 モデル生成の確認
- [ ] 基礎梁データを入力
- [ ] 解析モデル作成を実行
- [ ] エラーが発生しない
- [ ] 以下の要素が作成されていることを確認:
  - FoundationNode (基礎梁節点)
  - Beam (基礎梁要素)
  - RigidBody (CapNode → FoundationNode の偏心接続)

### 4.2 偏心接続の確認
- [ ] 基礎梁節点のZ座標 ≠ 杭頭のZ座標の場合
- [ ] RigidBodyのマスター-スレーブ関係:
  - マスター: FoundationNode
  - スレーブ: CapNode
- [ ] アーム長さが正しい（基礎梁高さの半分程度）

### 4.3 断面特性の確認
- [ ] 基礎梁要素のSection.Aが正しい（Width × Height）
- [ ] Section.Iが正しい（Width × Height³ / 12）
- [ ] Section.Jが正しい（torsion constant）
- [ ] Section.Eが入力値と一致（YoungModulus）
- [ ] Section.Gが入力値と一致（ShearModulus）

### 4.4 簡易解析テスト
**ケース: 2本杭 + 1本基礎梁**
1. 杭を2本配置: (0,0,-10)～(0,0,0), (5,0,-10)～(5,0,0)
2. 基礎梁節点: (0,0,0.5), (5,0,0.5)
3. 基礎梁要素: Node1 → Node2, 幅0.5m, 高さ0.8m
4. 荷重: 基礎梁中央（x=2.5）に鉛直荷重 100kN
5. 解析実行
6. 結果確認:
   - [ ] 両杭に荷重が分散される（各約50kN）
   - [ ] 基礎梁に曲げモーメントが発生
   - [ ] 数値的に妥当な結果

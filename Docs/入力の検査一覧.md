# 入力の検査一覧

入力におかしな値を入れたとき、どの段階で捕まるかの一覧です。
各行は試験 (`TestProject1/InputCheckCoverageTests.cs`) が計算例9 に実際にその値を入れて確かめた結果で、
実装が変わると試験が落ちます。作り直しは `UPDATE_INPUT_CHECK_TABLE=1` を付けて試験を走らせます。

- **画面で受け付けない**: 入力した値を受け付けず、範囲に収めるか元の値に戻す
- **解析の前に止める**: 解析を始める前の検査で止め、直す場所を示す
- **解析の前に注意**: 解析は止めないが、解析の前の確認と「入力の診断」に出す
- **計算書に書く**: 計算書の「計算条件・仮定」章の「入力についての注意」に書く
